# Сценарии проверки Indestructible — простым языком

## Главная идея продукта

**Всё нужное для VPN/чата — внутри продукта.**  
Отдельное приложение AmneziaVPN **не обязательно**. Оно только «дополнительно», если человек уже привык к Amnezia.

| Путь | Где живёт | Нужно ли вам что-то ставить |
|------|-----------|------------------------------|
| **A. VPN другу (основной)** | WebRTC внутри страницы | Нет |
| **B. VPN-движок в приложении** | Go userspace внутри нашего сервера | Нет |
| **C. AmneziaVPN import** | Чужое приложение | Уже стоит у вас — но **не цель продукта** |
| **D. Kernel WireGuard** | Драйвер Windows | UAC/админ — не делаем по умолчанию |

---

## Что от вас НЕ требуется сейчас

1. Ставить WireGuard отдельно  
2. Разрешать UAC  
3. Импортировать conf в AmneziaVPN  
4. Разводить ноутбук и телефон по разным Wi‑Fi (это этап «поле»)  

Эти пункты были в «критике» как **максимальная** проверка железа, а не как условие «чтобы продукт заработал».

## Сценарий 1 — Один ПК, один браузер (дымовой, 2 минуты)

**Цель:** убедиться, что приложение живо.

1. Откройте: `http://127.0.0.1:8090/?role=alice`
2. Должны увидеть:
   - чат с Bob (demo)
   - бейдж `4 STUN · P2P 85% + Nostr relay 15%`
   - кнопки: **Дать VPN другу**, **Запросить VPN**, **VPN в приложении**, **Уведомления**
3. Нажмите **VPN в приложении**
4. Статус: `Движок: up/в приложении` (или `up/userspace`)

**Успех:** без ошибок, движок up.  
**Провал:** белый экран / кнопка не жмётся / статус error.

## Сценарий 2 — Одна Wi‑Fi, два «устройства» (рекомендую сегодня)

У вас ноутбук и телефон **в одной Wi‑Fi City** — это **нормально** для первого этапа.  
Так проверяется продукт «как у двух людей в кафе», ещё не «через интернет операторов».

### 2A. Два окна на ноутбуке (без телефона)

1. Окно 1 Chrome: `http://127.0.0.1:8090/?role=alice`
2. Окно 2 Chrome (инкогнито): `http://127.0.0.1:8090/?role=bob`
3. Alice: **Дать VPN другу** → вставить ID Bob (или demo-поток)
4. Bob: принять, если появится входящий запрос

**Успех:** статусы sharing/connected, сообщения уходят.  
Это уже ценный тест **внутри продукта**, без Amnezia.

### 2B. Ноутбук + телефон в **той же** Wi‑Fi

1. Узнайте IP ноутбука в Wi‑Fi (раньше был вида `10.x.x.x`, смотрите `ipconfig`)
2. На ноутбуке сервер должен слушать не только localhost. Если телефон не открывает — напишите, включим `0.0.0.0`.
3. На телефоне в браузере: `http://<IP-ноутбука>:8090/?role=bob`
4. На ноутбуке: `http://127.0.0.1:8090/?role=alice`
5. Тот же сценарий «дать / запросить VPN»

**Успех:** телефон видит UI, роли работают, invite/accept в одной сети.

**Это не Dual-WiFi.** Это **same-WiFi dual-device** — и его достаточно, чтобы проверить 80% продукта.

## Сценарий 3 — Как потом развести сети (когда захотите Dual-WiFi)

Сейчас оба в Wi‑Fi City → одна сеть. Варианты развести:

| Способ | Как | Сложность |
|--------|-----|-----------|
| **Раздача с телефона** | Телефон: модем/hotspot. Ноутбук подключить к hotspot телефона **или** наоборот: ноут на City, телефон только LTE | Просто |
| **Гостевая Wi‑Fi** | Роутер: гостевая сеть для телефона | Средне |
| **Другой дом/кафе** | Телефон в другом месте | Поле |

### Рекомендуемый простой dual-network позже

1. Ноутбук остаётся на Wi‑Fi City (Alice + сервер, если нужен local hub)  
2. На телефоне **выключить Wi‑Fi**, оставить **LTE** (Bob)  
3. Проблема: с LTE телефон **не откроет** `http://10.x.x.x:8090` (домашний IP из мобильного интернета не виден)  
4. Поэтому dual-network в продукте идёт через **Nostr invite / WebRTC**, а не через «открой IP компа с LTE»

Пока **нет** опубликованного HTTPS-фронта в интернете, полный dual-network «телефон на LTE открыл наш UI» упирается в доставку PWA.  
Код signaling/relay уже есть; не хватает либо:
- PWA на публичном хосте (вы раньше не хотели Cloudflare/домен), либо  
- установки PWA заранее, пока телефон ещё в той же Wi‑Fi, потом уход в LTE.

**Практичный компромисс без домена:**

1. Пока телефон в Wi‑Fi City — открыть UI, «Добавить на экран» (PWA)  
2. Выключить Wi‑Fi на телефоне (LTE)  
3. Открыть PWA с экрана (оффлайн shell + Nostr)  
4. Проверить invite/gift-wrap  

Это и есть честный dual-network без своего сервера в интернете.

## Сценарий 4 — Уведомления (Push) — только если хотите

1. Обычный Chrome/Edge: `http://127.0.0.1:8090/?role=alice`
2. Кнопка **Уведомления** → **Разрешить**
3. Успех: `Push: subscribed`

Если `permission_denied` — не ломает VPN. Можно пропустить.

## Сценарий 5 — AmneziaVPN (ОПЦИОНАЛЬНО, не цель)

У вас AmneziaVPN уже стоит — **этого достаточно как внешнего клиента**, но продукт **не должен** от него зависеть.

Делать **только если** хотите сравнить conf:

1. В UI: **Дополнительно** → «Экспорт conf в AmneziaVPN»  
2. Или папка `Desktop\Indestructible-Amnezia\`  
3. Import в Amnezia  

Успех: Amnezia приняла файл.  
Интернет через demo-peer может не пойти — это нормально.

**Мы сознательно не делаем Amnezia обязательной.** Основной путь — кнопки VPN в продукте.
