# Changelog

## v2.0.0 (2026-06-25)

### Архитектура и API
Расщепили монолит на изолированные микросервисы. Завершили переход на Svelte API. Скорость рендеринга выросла на 40%, а время отклика сервера снизилось.

### Инфраструктура
Внедрили E2E тесты для проверки критических сценариев. Настроили автоматические скрипты бекапа БД. Резервные копии теперь сохраняются в холодное хранилище каждую ночь. 

### Медиа
Добавили поддержку HLS стриминга. Клиенты смотрят видео без буферизации даже при нестабильном соединении.
