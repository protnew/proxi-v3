## MVP (Phase 0): VPN-ядро

Только VPN. Без чата. Без контента.

**Цель:** Два компьютера соединяются через WireGuard mesh. Один = exit node.

**Компоненты:**
1. Tauri shell (UI)
2. Go VPN Manager (Netbird-based)
3. WireGuard туннель
4. STUN/TURN для NAT traversal

**UX:**
1. Установил приложение
2. Сгенерировал ключи
3. Поделился публичным ключом с другом (QR/копипаст)
4. Друг добавил тебя
5. Нажал «Поделись интернет» → друг подключился через тебя

## Расширение от ядра

Phase 0 → 1 → 2 → 3 = VPN → +Чат → +Контент → +Платформа

Каждая фаза = новый модуль поверх VPN mesh.
