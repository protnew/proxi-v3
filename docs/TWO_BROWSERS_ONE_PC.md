## Два окна = два пользователя

| Окно | Как | Кто |
|------|-----|-----|
| A | Chrome обычный → http://127.0.0.1:5173/ | Alice |
| B | Chrome **Incognito** или Edge → тот же URL | Bob |

**Почему не две обычные вкладки Chrome:** общий `localStorage` = один JWT = один человек.

## Мессенджер

### Вариант A — быстрый demo (если видны кнопки)
1. Окно A: **👤 Alice (T1)**  
2. Окно B: **👤 Bob (T2)**  
3. Дальше как в шагах 3–6 ниже (✏️ + ID + сообщение).

### Вариант B — вручную (основной)

| Шаг | Где | Действие | Ожидание |
|-----|-----|----------|----------|
| 1 | Alice | **Мой ID → только кнопка 📋** | В буфере **полный** ID (длинный). На экране обрезка `xxxx…yyyy` — **глазами не копировать** |
| 2 | Bob | Тоже **только 📋** | Полный ID Bob |
| 3 | Alice | **✏️** → User ID = **полный ID Bob** → **Начать чат** | Чат открыт; **закрой лишние modal/overlay** (X), не только Escape |
| 4 | Alice | `привет от Alice` → Enter | Сообщение видно **у Alice** |
| 5 | Bob | Чат в списке **или** ✏️ + полный ID Alice → Начать | Текст Alice виден **у Bob** (лучше без F5) |
| 6 | Bob | `ок от Bob` | Alice видит ответ |

**Провал теста:** вставили обрезанный ID с экрана → peer не находится.

## VPN (в одном окне)

| Шаг | Действие | Ожидание |
|-----|----------|----------|
| 1 | Панель VPN → **Настоящий SOCKS5** | Режим выбран |
| 2 | **Включить** | UI: **ON · SOCKS**, адрес `127.0.0.1:10808` |
| 3 | **Проверить IP через VPN** | IP **внутри приложения** (через SOCKS) |
| 4 | Опц. CLI | `curl.exe --socks5 127.0.0.1:10808 https://api.ipify.org` |
| 5 | Отключить | Отключён |

**Важно:** это **не** смена IP всей Windows. Системный IP в браузере без proxy settings **может не измениться** — так и должно быть. Чат **не зависит** от VPN.

## Типичные ловушки

| Симптом | Причина | Что сделать |
|---------|---------|-------------|
| Одинаковый ID в A и B | Один профиль Chrome | Incognito / Edge |
| Сообщение не доходит | Обрезанный ID | Только 📋 |
| Клики «в никуда» | Overlay/dialog сверху | Закрыть modal (X) |
| «VPN не сменил IP Windows» | Ждали system VPN | Смотрите IP-кнопку в UI / curl --socks5 |
| Нет Мой ID | Backend down | start-messenger-dev.ps1 + F5 |
