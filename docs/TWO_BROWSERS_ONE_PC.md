# Как тестировать в двух браузерах на одном ПК

## Перед стартом (1 раз)

1. Запусти backend + UI:
```powershell
cd "C:\Obsidian\New\Projects\04-Неубиваемый-контент V2\.04-Src"
pwsh .\scripts\start-messenger-dev.ps1
```
2. Проверь:
   - API: http://127.0.0.1:8080/api/health → OK
   - UI:  http://127.0.0.1:5173/

**Важно:** оба окна ходят на **один** backend `:8080`. Иначе сообщения не сойдутся.

---

## Схема окон

| Окно | Что открыть | Кто |
|------|-------------|-----|
| A | Chrome (обычное) → http://127.0.0.1:5173/ | Alice |
| B | Chrome **Incognito** *или* Edge → http://127.0.0.1:5173/ | Bob |

Почему Incognito/другой браузер: у каждого свои cookies/`localStorage` → **два разных пользователя** (два JWT, два ID).

Не открывай две обычные вкладки одного Chrome — они делят storage и будут одним человеком.

---

## Мессенджер (5 минут)

### 1. Alice (окно A)
1. Дождись сайдбара: **Мой ID** + кнопка 📋.
2. Нажми **📋** — ID Alice в буфере.
3. (Опционально) вставь ID в блокнот как «Alice».

### 2. Bob (окно B)
1. Тоже **Мой ID** → **📋**.
2. Сохрани ID Bob.

### 3. Alice пишет Bob
1. В окне A нажми **✏️** (новый чат).
2. В поле **User ID** вставь **ID Bob** (полный, из буфера окна B).
3. Имя можно `Bob`.
4. **Начать чат**.
5. В поле сообщения: `привет от Alice 123` → Enter (или отправить).
6. Сообщение должно появиться **у Alice** сразу (optimistic).

### 4. Bob читает
1. В окне B либо чат появится в списке, либо:
2. **✏️** → вставь **ID Alice** → **Начать чат**.
3. Должен увидеть `привет от Alice 123`.

### 5. Обратно
1. Bob пишет `ответ Bob 456`.
2. Alice видит ответ в том же чате.

**Готово, если:** текст есть в обоих окнах без F5 (или после F5 история тоже есть).

---

## VPN (в любом одном окне)

1. Внизу сайдбара панель **VPN**.
2. Режим **Настоящий SOCKS5**.
3. **Включить настоящий SOCKS5**.
4. Статус: **ON · SOCKS · socks5**, адрес `127.0.0.1:10808`.
5. **Проверить IP через VPN** → появляется публичный IP.
6. (Опц.) в PowerShell:
```powershell
curl.exe --socks5 127.0.0.1:10808 https://api.ipify.org
```
7. **Отключить VPN**.

VPN **не обязан** быть ON, чтобы чат работал. Чат и VPN независимы.

## Типичные ошибки

| Симптом | Причина | Что сделать |
|---------|---------|-------------|
| Оба окна — один ID | Один профиль Chrome | Incognito или Edge |
| Сообщение не у Bob | Вставлен короткий ID / чужой | Копируй ID кнопкой 📋 у того, кому пишешь |
| 401 / нет Мой ID | Backend не запущен | `start-messenger-dev.ps1`, F5 |
| VPN клик «ничего» | Старая вкладка без HMR | Жёсткий F5 / новый URL |
| Пустые пузыри | Старый кэш | Ctrl+F5 |
